# Example prompts

Attach the photos (1–2 clear ones of the person) and an mp3 of the song you want. Claude picks the song's main part, syncs the cuts to it, and asks only for what's missing.

## Invites
```text
Create a cool funky desi pop maximalism motion graphics birthday invite for my house party.
This is me [photos]. Use the main part of this song [mp3]. Address: <address>. 8 PM onwards,
before also works (make it a joke). Gen-Z comedic vibe. End with a personalised card for each
guest with their photo — make it templatised.
```
```text
Make a 20-second Diwali party invite in this style for our society terrace. Family friendly,
include rangoli and diyas, Hindi + English text. Song attached.
```
```text
Sangeet night invite for my sister's wedding — cartoon her and the groom from these photos,
bhangra energy, dress code "full desi", venue and date at the end.
```

## After the party

```text
Party's done, everyone's gone. 10-second video: "Thank you for coming, hope you enjoyed last
```


## Changes you can ask for afterwards
- "Use this photo instead of that one in the reveal."
- "The name should be RIYA, not Riyaa."
- "Remove the cigarette and weed stuff — make it family friendly."
- "Dress code should be 'Kapde', and remove 'gifts optional'."
- "Use this song instead" (attach the mp3). The whole timeline re-syncs to the new beat.
- "Make one for each guest in this list" (names + photo paths).
- "Show it to me in an artifact" (a phone-frame player page).

## Tips
- **Songs:** the skill works best with a clear hook or drop. If you're unsure, ask *"what famous song fits this?"*. Claude suggests a few, and you supply the mp3.
- **Unknown facts:** say anything you don't know yet (e.g. "date TBD"). The skill keeps it as a template field instead of inventing it.
- **Instagram:** upload the video silent and add the song in-app, because copyrighted tracks can get muted.
